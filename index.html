Why clients work with a full-stack freelance developer instead of an agency

You talk directly to the person writing the code - no account manager relaying messages, no hand-off between a design team and a dev team. I scope the project, build it, and stay on for fixes and updates after launch, so there's one person accountable for the whole thing. Because I also teach Computer Science, I write code and documentation with the assumption that someone else may need to read it later - which matters if you ever bring in another developer down the line.
